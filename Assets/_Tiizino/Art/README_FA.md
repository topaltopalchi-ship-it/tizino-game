# فایل اصلی آیکون تیزینو

فایل تأییدشدهٔ کاربر باید با نام `tiizino-icon.png` در همین پوشه قرار گیرد.

**الزام مهم:** فایل باید دقیقاً همان تصویر اصلی ارسال‌شده از سوی کاربر باشد؛ هیچ برش، تغییر اندازهٔ ذخیره‌شده به‌جای اصل، تغییر رنگ، بازطراحی یا دست‌کاری نوشته انجام نشود. این README جایگزین فایل تصویر نیست و وجود آن به معنی ثبت تصویر اصلی نیست.

پس از ثبت فایل اصلی، در Unity گزینهٔ `Tools → Tiizino → Apply Official App Icon` را اجرا کنید تا تصویر برای آیکون Android تنظیم شود.
