# انتشار پیش‌نمایش وب تیزینو

پیش‌نمایش بازی از فایل‌های `Preview/grades.html` و بانک سؤال‌های پایهٔ اول و دوم ساخته می‌شود. تست‌های خودکار مخزن مستقل از انتشار وب اجرا می‌شوند.

## فعال‌سازی یک‌بارهٔ GitHub Pages

در اجرای فعلی، مرحلهٔ انتشار متوقف شده چون GitHub Pages هنوز برای مخزن فعال نیست و توکن GitHub Actions اجازهٔ ایجاد تنظیم Pages را ندارد (`Resource not accessible by integration`). این محدودیت را نمی‌توان با تغییر فایل‌های مخزن دور زد.

مالک مخزن باید یک‌بار این مراحل را انجام دهد:

1. مخزن `topaltopalchi-ship-it/tizino-game` را در GitHub باز کند.
2. به **Settings → Pages** برود.
3. در **Build and deployment → Source**، گزینهٔ **GitHub Actions** را انتخاب کند و ذخیره کند.
4. سپس workflow با نام **Deploy playable grade preview** را از تب **Actions** دوباره اجرا کند؛ یا یک commit جدید روی شاخهٔ `main` قرار دهد.

پس از فعال‌سازی، باید اجرای workflow و آدرس خروجی Pages بررسی شود؛ تا آن زمان لینک پیش‌نمایش منتشرشده را آماده یا فعال فرض نکنید.

## بررسی کیفیت

Workflowهای بررسی بانک سؤال و پیش‌نمایش، تست‌های خودکار فایل‌ها هستند. موفقیت آن‌ها به معنی تأیید اجرای واقعی Unity، سازگاری موبایل یا ساخته‌شدن APK نیست.
