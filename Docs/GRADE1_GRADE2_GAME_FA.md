# بستهٔ بازی پایهٔ اول و دوم

## محتوای آماده
- پایهٔ اول: `Assets/_Tiizino/Resources/Grade1_QuestionBank.json`
- پایهٔ دوم: `Assets/_Tiizino/Resources/Grade2_QuestionBank.json`

هر بانک ۱۲ سؤال تازه در سه بخش دارد. این‌ها محتوای اولیهٔ قابل بازی برای نمونه‌سازی هستند، نه ادعای پوشش کامل برنامهٔ درسی یا تحلیل تکمیل‌شدهٔ تمام آزمون‌های ده‌ساله. متن سؤال‌های آزمون‌ها عیناً کپی نشده است.

## انتخاب پایه در اجرا
کنترلر مرحله، اگر فیلد بانک سؤال در Inspector خالی باشد، مقدار `PlayerPrefs.GetInt("Tiizino.SelectedGrade", 1)` را می‌خواند:
- مقدار 1: بانک پایهٔ اول
- مقدار 2: بانک پایهٔ دوم

پیش از بارگذاری صحنه، رابط انتخاب پایه می‌تواند این مقدار را با `PlayerPrefs.SetInt("Tiizino.SelectedGrade", grade)` ثبت کند. اگر هیچ مقداری ثبت نشود، پایهٔ اول انتخاب می‌شود.

## اجرای نمونه
1. پروژه را در Unity باز کنید.
2. از منوی `Tools > Tiizino > Create Stage 01 Scene` صحنه را بسازید.
3. صحنه را اجرا کنید؛ در حالت پیش‌فرض بانک پایهٔ اول بارگذاری می‌شود.
4. برای آزمودن پایهٔ دوم، مقدار `Tiizino.SelectedGrade` را پیش از ساخت مرحله روی 2 تنظیم کنید؛ رابط انتخاب پایهٔ نهایی هنوز باید به صفحهٔ شروع متصل شود.

## وضعیت
بانک‌ها و اتصال انتخاب بانک در کد ثبت شده‌اند. این commit به‌تنهایی اثبات‌کنندهٔ اجرای Unity، صحت بصری متن فارسی یا ساخت APK نیست. صدای پایان مرحله اضافه نشده است.
