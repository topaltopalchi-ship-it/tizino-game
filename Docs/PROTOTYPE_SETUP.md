# اجرای نمونهٔ سه‌بعدی مرحلهٔ اول

این کد یک نمونهٔ اولیهٔ رویه‌ای است؛ مدل‌های حرفه‌ای، انیمیشن نهایی و آزمون روی دستگاه واقعی هنوز اضافه نشده‌اند.

## مراحل
1. در Unity Hub یک پروژهٔ **3D (URP)** با Unity 6 بسازید.
2. پوشهٔ `Assets/_Tiizino/Scripts/Gameplay` را از این مخزن به پروژه منتقل کنید.
3. یک صحنهٔ جدید به نام `Stage01_Bridge` بسازید و ذخیره کنید.
4. یک Empty GameObject به نام `Stage Controller` بسازید.
5. اسکریپت `BridgeStageController` را به آن اضافه کنید.
6. دکمهٔ Play را بزنید؛ محیط موقت، پل، درخت‌ها و رابط سؤال در زمان اجرا ساخته می‌شوند.

## نکته‌های فنی
- برای سریع‌بودن نمونه از primitiveهای Unity و UI قدیمی استفاده شده است؛ این نسخه نمایش فنی اولیه است، نه کیفیت نهایی.
- در بعضی نسخه‌های Unity ممکن است لازم باشد Input Handling را روی Both بگذارید تا Standalone Input Module کار کند.
- متن فارسی با فونت پیش‌فرض تضمین‌شده نیست؛ برای نسخهٔ محصول باید فونت فارسی مجاز اضافه و راست‌چین‌سازی درست پیاده‌سازی شود.
- پاسخ نادرست در نمونه توضیح کوتاه می‌دهد و پس از مکث، امکان تلاش دوباره فعال می‌شود؛ پاسخ درست به سؤال بعد می‌رود.
- پیش از ساخت APK، کامپایل و اجرا را در Unity بررسی کنید. این محیط به Unity Editor دسترسی ندارد و نمی‌تواند موفقیت کامپایل یا رفتار ورودی روی دستگاه واقعی را تأیید کند.
