# چک‌لیست آزمون نمونهٔ تیزینو

این چک‌لیست برای بررسی دستی نمونه در Unity Editor و سپس روی Android است. تیک‌ها را فقط پس از اجرای واقعی آزمون بزنید.

## پیش از اجرا
- [ ] پروژه با نسخهٔ Unity 6 و قالب 3D (URP) باز می‌شود.
- [ ] فایل‌های اسکریپت بدون خطای کامپایل در Console هستند.
- [ ] صحنهٔ `Stage01_Bridge` ذخیره شده و `BridgeStageController` به یک GameObject متصل است.
- [ ] فایل `Stage01_Bridge.json` در فیلد **Question Bank Json** تنظیم شده یا عمداً خالی گذاشته شده است.
- [ ] در صورت استفاده از فونت اختصاصی، مجوز فونت و وجود حروف فارسی بررسی شده است.

## آزمون سؤال‌ها
- [ ] با فایل JSON معتبر، چهار سؤال از بانک داده نمایش داده می‌شوند.
- [ ] هر سؤال سه دکمهٔ پاسخ دارد و متن گزینه‌ها با JSON مطابقت دارد.
- [ ] پاسخ درست ستاره اضافه می‌کند و تختهٔ پل بعدی را نمایان می‌کند.
- [ ] پاسخ نادرست مرحله را جلو نمی‌برد و پس از مکث امکان تلاش دوباره می‌دهد.
- [ ] پس از سؤال آخر، پیام پایان و تعداد ستاره‌ها نمایش داده می‌شود.
- [ ] با تنظیم `Stage Complete Clip`، دکمهٔ «آزمایش صدای پایان مرحله» فعال می‌شود و کلیپ را با لمس پخش می‌کند.
- [ ] پس از پاسخ درست به آخرین سؤال، افکت پایان مرحله فقط یک بار پخش می‌شود.
- [ ] دکمهٔ «شنیدن دوبارهٔ سؤال» در صورت اتصال AudioClipهای مناسب، صدای سؤال جاری را تکرار می‌کند.

## آزمون ورودی نامعتبر و بازسازی
- [ ] با فیلد JSON خالی، سؤال‌های داخلی نمایش داده می‌شوند.
- [ ] با JSON خراب یا سؤال دارای گزینهٔ خالی، هشدار مناسب در Console دیده می‌شود و بانک داخلی استفاده می‌شود.
- [ ] پس از اجرای یک بانک معتبر و سپس بازسازی با فایل نامعتبر، سؤال‌های قبلی به‌اشتباه باقی نمی‌مانند.
- [ ] اجرای دوبارهٔ فرمان **Build Tiizino Bridge Stage** باعث باقی‌ماندن چند رابط کاربری یا چند محیط هم‌زمان نمی‌شود.

## رابط فارسی و Android
- [ ] حروف فارسی در سؤال‌ها و گزینه‌ها به‌درستی شکل می‌گیرند و ترتیب راست‌به‌چپ صحیح است.
- [ ] متن‌های بلند در اندازه‌های مختلف صفحه بریده یا روی دکمه‌ها هم‌پوشان نمی‌شوند.
- [ ] همهٔ دکمه‌ها با لمس کار می‌کنند و اندازهٔ لمس برای کودک مناسب است.
- [ ] تغییر اندازهٔ صفحه و چرخش دستگاه (اگر پشتیبانی می‌شود) رابط را خراب نمی‌کند.
- [ ] صدا با خاموش‌کردن/قطع صدا یا از دست رفتن فوکوس صوتی رفتار قابل‌قبول دارد.
