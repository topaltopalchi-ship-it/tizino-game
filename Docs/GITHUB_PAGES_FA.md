# انتشار پیش‌نمایش وب تیزینو

گردش‌کار `.github/workflows/deploy-preview.yml` فایل‌های پیش‌نمایش پایهٔ اول و دوم را می‌سازد و با GitHub Pages منتشر می‌کند.

## یک‌بار تنظیم در مخزن

اگر گردش‌کار در مرحلهٔ «Configure GitHub Pages» با خطای `Resource not accessible by integration` متوقف شد، توکن Actions اجازهٔ فعال‌کردن Pages را ندارد. مالک مخزن باید یک‌بار دستی این کار را انجام دهد:

1. مخزن را در GitHub باز کنید و وارد **Settings → Pages** شوید.
2. در بخش **Build and deployment**، گزینهٔ **Source** را روی **GitHub Actions** بگذارید.
3. تنظیم را ذخیره کنید و گردش‌کار **Deploy playable grade preview** را از زبانهٔ **Actions** دوباره اجرا کنید.

اگر گزینهٔ Pages در دسترس نیست، دسترسی مالک/مدیر مخزن یا سیاست‌های سازمانی باید بررسی شود؛ تغییر فایل‌های پروژه به‌تنهایی این مجوز حساب را ایجاد نمی‌کند.

## آدرس پیش‌نمایش

پس از اجرای موفق گردش‌کار، آدرس سایت در خلاصهٔ اجرای workflow و محیط `github-pages` نمایش داده می‌شود. تا پیش از موفقیت مرحلهٔ Deploy، آدرس منتشرشده را فعال و تأییدشده فرض نکنید.

پیش‌نمایش فقط نسخهٔ وب قابل‌بازی است و جایگزین ساخت، کامپایل یا آزمون APK در Unity نیست.
