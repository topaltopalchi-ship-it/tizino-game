# بازکردن اسکلت Unity تیزینو

این مخزن اکنون فایل‌های پایهٔ یک پروژهٔ Unity 6 را دارد؛ اما تا زمانی که پروژه در خود Unity باز و اجرا نشود، کامپایل یا اجرای واقعی تأییدشده محسوب نمی‌شود.

## ساخت صحنهٔ مرحلهٔ اول

1. Unity Hub را باز کنید و نسخهٔ **Unity 6.0 (6000.0.32f1)** را نصب کنید.
2. از Hub گزینهٔ **Add / Add project from disk** را انتخاب کنید و پوشهٔ اصلی مخزن را باز کنید؛ همان پوشه‌ای که `Assets`، `Packages` و `ProjectSettings` را دارد.
3. صبر کنید Unity بسته‌های `Packages/manifest.json` را دریافت و پروژه را وارد کند.
4. از منوی بالای Unity به **Tools → Tiizino → Create Stage 01 Scene** بروید.
5. صحنهٔ ساخته‌شده در `Assets/_Tiizino/Scenes/Stage01_Bridge.unity` ذخیره می‌شود. آن را باز کنید و Play را بزنید.
6. اگر خطای Console دیدید، متن کامل خطا را پیش از ساخت APK برطرف کنید.

## نکته‌ها

- ابزار ساخت صحنه، صحنه‌های دیگر موجود در Build Settings را حفظ می‌کند و مرحلهٔ تیزینو را به فهرست اضافه می‌کند.
- بانک سؤال پیش‌نویس در `Assets/_Tiizino/Resources/Stage01_FourLevels_DRAFT.json` قرار دارد.
- صدای گفتار فقط از کلیپ‌های صوتی‌ای پخش می‌شود که در Inspector تنظیم شده باشند؛ فایل صوتی از پیش پیکربندی نشده و TTS هنوز پیاده‌سازی نشده است.
- این راهنما جایگزین کامپایل Unity، آزمون روی دستگاه Android یا تأیید APK نیست.
