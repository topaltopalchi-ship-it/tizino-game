# بازکردن اسکلت Unity تیزینو

این مخزن اکنون فایل‌های پایهٔ یک پروژهٔ Unity 6 را دارد؛ اما تا زمانی که پروژه در خود Unity باز و اجرا نشود، کامپایل یا اجرای واقعی تأییدشده محسوب نمی‌شود.

## ساخت صحنهٔ مرحلهٔ اول

1. Unity Hub را باز کنید و نسخهٔ **Unity 6.0 (6000.0.32f1)** را نصب کنید.
2. از Hub گزینهٔ **Add / Add project from disk** را انتخاب کنید و پوشهٔ اصلی مخزن را باز کنید؛ همان پوشه‌ای که `Assets`، `Packages` و `ProjectSettings` را دارد.
3. صبر کنید Unity بسته‌های `Packages/manifest.json` را دریافت و پروژه را وارد کند.
4. از منوی بالای Unity به **Tools → Tiizino → Create Stage 01 Scene** بروید.
5. صحنهٔ ساخته‌شده در `Assets/_Tiizino/Scenes/Stage01_Bridge.unity` ذخیره می‌شود. آن را باز کنید و Play را بزنید.
6. اگر خطای Console دیدید، متن کامل خطا را پیش از ساخت APK برطرف کنید.

## نکته‌ها

- ابزار ساخت صحنه، صحنه‌های دیگر موجود در Build Settings را حفظ می‌کند و مرحلهٔ تیزینو را به فهرست اضافه می‌کند.
- بانک سؤال پیش‌نویس در `Assets/_Tiizino/Resources/Stage01_FourLevels_DRAFT.json` قرار دارد.
- صدای گفتار فقط از کلیپ‌های صوتی‌ای پخش می‌شود که در Inspector تنظیم شده باشند؛ فایل صوتی از پیش پیکربندی نشده و TTS هنوز پیاده‌سازی نشده است.
- این راهنما جایگزین کامپایل Unity، آزمون روی دستگاه Android یا تأیید APK نیست.

## تنظیم آیکون رسمی برنامه

پس از قرارگرفتن تصویر اصلیِ تأییدشده (بدون هیچ ویرایش) در مسیر `Assets/_Tiizino/Art/tiizino-icon.png`، در Unity گزینهٔ **Tools → Tiizino → Apply Official App Icon** را اجرا کنید. اگر فایل در آن مسیر وجود نداشته باشد، ابزار خطا می‌دهد و آیکون جایگزین نمی‌سازد. تصویر باید همان فایل اصلی باشد؛ برش، بازطراحی، تغییر رنگ یا دست‌کاری نوشته مجاز نیست. سپس در **Project Settings → Player → Android → Icon** نتیجه را بررسی کنید.

## آماده‌سازی Android (پس از موفقیت Play Mode)

1. در Unity Hub برای همان نسخه، ماژول **Android Build Support** را همراه با **Android SDK & NDK Tools** و **OpenJDK** نصب کنید.
2. در Unity از **File → Build Profiles** (یا **Build Settings** در نسخه‌هایی که این پنجره را دارند) پلتفرم Android را انتخاب کنید و **Switch Platform** را بزنید.
3. مطمئن شوید صحنهٔ `Assets/_Tiizino/Scenes/Stage01_Bridge.unity` در فهرست صحنه‌های ساخت فعال است.
4. در **Project Settings → Player**، شناسهٔ بسته (Package Name) یکتا تنظیم کنید و جهت صفحه و حداقل نسخهٔ Android را مطابق دستگاه هدف انتخاب کنید.
5. ابتدا یک Build آزمایشی بسازید و روی گوشی نصب کنید. اندازهٔ متن فارسی، برش صفحه، لمس دکمه‌ها و عملکرد بازگشت/شروع مجدد را دستی بررسی کنید.
6. برای انتشار، کلید امضای خصوصی را در مخزن Git ثبت نکنید؛ از تنظیمات امن و پشتیبان‌گیری‌شدهٔ خودتان استفاده کنید.

**شرط توقف:** اگر Console خطای کامپایل دارد، هنوز سراغ APK نهایی یا انتشار نروید. تست‌های GitHub Actions فقط تست‌های ایستای فایل‌ها هستند و موفقیت Build اندروید را اثبات نمی‌کنند.
