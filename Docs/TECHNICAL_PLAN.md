# طرح فنی تیزینو

## تصمیم‌های پایه
- موتور: Unity 6، Universal Render Pipeline (URP).
- سبک بصری: سه‌بعدی stylized، رنگ‌های گرم، نورپردازی سبک و محیط‌های خوانا.
- ورودی لمسی با هدف‌های بزرگ و رابط فارسی راست‌به‌چپ.
- معماری داده‌محور؛ منطق بازی جدا از نمایش.

## حلقهٔ اصلی بازی
۱. معرفی داستانی؛ ۲. نمایش محیط و معما؛ ۳. دریافت پاسخ؛ ۴. بازخورد مهربان؛ ۵. اعطای ستاره و ثبت پیشرفت؛ ۶. پیشنهاد تمرین بعدی.

## ۱۲ مرحله
### پایهٔ اول
۱. نجات پل جنگل — الگوهای دیداری و عددی ساده.
۲. دروازهٔ شکل‌ها — شکل‌ها و روابط مکانی.
۳. باغ موجودات عجیب — دسته‌بندی و توجه.
۴. غار ستاره‌های گمشده — توالی، حافظه و منطق مقدماتی.

### پایهٔ دوم
۵. قلعهٔ رمزها — الگوهای چندگامی.
۶. رودخانهٔ اعداد — روابط عددی.
۷. کتابخانهٔ واژه‌ها — واژگان و درک مطلب.
۸. هزارتوی آینه‌ها — چرخش ذهنی و جهت‌یابی.

### پایهٔ سوم
۹. معبد هوش — استنتاج قانون.
۱۰. کارگاه مخترعان — مسئله‌های چندمرحله‌ای.
۱۱. جزیرهٔ تصمیم‌ها — مقایسه و انتخاب راه‌حل.
۱۲. نبرد نهایی ستاره‌ها — تمرین ترکیبی.

## سازگاری دستگاه‌ها
- سه سطح کیفیت: Low / Balanced / High.
- سطح پایین: سایه‌های سنگین و ذرات پرهزینه خاموش.
- تعداد مواد و draw call پایین؛ نورهای پویا محدود.
- تنظیمات کیفیت قابل انتخاب و تست روی دستگاه‌های کم‌حافظه.
- نرخ فریم پایدار از جلوه‌های اضافی مهم‌تر است.

## دشواری تطبیقی
سطح سؤال بر اساس روند پاسخ‌ها و نیاز به راهنمایی تنظیم شود. پاسخ غلط فرصتی برای یادگیری باشد، نه تنبیه. از برچسب قطعی «باهوش/کم‌هوش» یا تضمین قبولی خودداری شود.

## داده و درآمدزایی
نمونهٔ اولیه پیشرفت را محلی نگه دارد. اتصال ابری نیازمند سیاست حریم خصوصی و رضایت والد است. خرید یا اشتراک هنوز پیاده‌سازی نشده؛ در آینده قیمت و تمدید باید شفاف و خرید نیازمند رضایت والد باشد.
