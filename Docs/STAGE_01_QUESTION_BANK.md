# بانک سؤال مرحلهٔ ۱: نجات پل جنگل

این بانک، نمونه‌سؤال‌های تمرینیِ تألیفی است؛ سؤال آزمون رسمی یا نمونه‌سؤال سال‌های گذشته نیست. پاسخ‌ها با اندیس صفرمبنای گزینه‌ها نوشته شده‌اند تا هنگام ورود به `QuestionData` اشتباه نشوند.

## قرارداد داده

- `audioPhraseId` اختیاری است. اگر فایل صوتی برای آن شناسه تعریف نشده باشد، بازی باید همچنان با متن کار کند.
- برای مرحلهٔ نمونه، شناسه‌های `grade1_bridge_q1` تا `grade1_bridge_q4` با نمونهٔ فعلی `BridgeStageController` هماهنگ‌اند.
- گزینه‌ها کوتاه و قابل‌خواندن باشند؛ سؤال‌های صوتی نیز باید متن هم‌زمان داشته باشند.
- پاسخ اشتباه نباید باعث از دست رفتن پیشرفت یا تنبیه کودک شود.

## سؤال‌های پیشنهادی

### ۱. الگوی رنگی
- شناسه: `grade1_bridge_q1`
- پرسش: قرمز، آبی، قرمز، آبی؛ بعدی کدام رنگ است؟
- گزینه‌ها: قرمز / سبز / زرد
- پاسخ درست (اندیس): `0`
- توضیح: الگو یکی‌درمیان تکرار می‌شود.

### ۲. الگوی شکل‌ها
- شناسه: `grade1_bridge_q2`
- پرسش: دایره، دایره، ستاره، دایره، دایره؛ بعدی کدام شکل است؟
- گزینه‌ها: ستاره / مربع / دایره
- پاسخ درست (اندیس): `0`
- توضیح: پس از دو دایره، یک ستاره می‌آید.

### ۳. دنبالهٔ عددی
- شناسه: `grade1_bridge_q3`
- پرسش: ۱، ۲، ۳؛ عدد بعدی چیست؟
- گزینه‌ها: ۴ / ۵ / ۲
- پاسخ درست (اندیس): `0`
- توضیح: هر بار یک واحد اضافه می‌شود.

- شناسه: `grade1_bridge_q4`

- گزینه‌ها: سیب / گلابی / صندلی

- توضیح: صندلی وسیله است و دو مورد دیگر میوه‌اند.
